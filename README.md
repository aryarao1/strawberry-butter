# Strawberry Butter

A playful strawberry paper-doll book with fixed rooms, movable dolls, dress-up, a bath, and Kitty. No scores or goals.

## Play

Open the GitHub Pages site, or serve this folder locally with any static web server. Turn Sound on to hear the girls greet each other and Kitty meow. Use Share a playable copy to download an offline HTML version.

Arrangements are saved locally in your browser. No account or server is needed to play.

## Publishing

In GitHub Settings → Pages, publish from the main branch and the root folder. All paths are relative, so project-site URLs work.
