# Strawberry Butter

A playful strawberry paper-doll book with fixed rooms, movable dolls, dress-up, a bath, and Chibs. No scores or goals.

## Play

Open the GitHub Pages site, or serve this folder locally with any static web server. Turn Sound on to hear the girls greet each other and Chibs meow. Use Share a playable copy to download an offline HTML version.

Arrangements are saved locally in your browser. No account or server is needed to play.

## Publishing

In GitHub Settings → Pages, publish from the main branch and the root folder. All paths are relative, so project-site URLs work.

## Credits

Original illustrations generated for this game. Girl greeting clips synthesized using installed macOS Yuna and Kyoko voices.

Kitten sound: [Kitten Mew by AntumDeluge](https://opengameart.org/content/kitten-mew), released under CC0 and included unchanged.

Lily has loose wavy pink hair with a fringe. Her towel hairstyle is a high ponytail. Chibs is the cat. Lily and Cherry use Korean and Japanese system voices for their English greetings; pronunciation depends on those voices.

Lily and Cherry take turns talking and gently playing together continuously while the closet is open. No subtitles are shown. Sound off, leaving the closet, closing the book, or hiding the page stops their conversation.
